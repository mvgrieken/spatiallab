# Release #001 — Ask Your Room

**Live:** 2026-08-03 (preview) / 2026-08-03 (spatiallab.atthis.ai) ·
**Status:** private preview behind login

## The idea

> Film your room. Ask it a question.

A ~10 second guided camera sweep in Safari; the browser picks ~6 usable
frames, downscales and compresses them on-device, and a vision-capable Claude
model returns observations and answers — each one anchored to a real frame
with a marker, visible evidence, and an honest confidence label (High
confidence / Likely / Uncertain).

## What shipped

- Guided camera sweep with live instructions; photo-upload fallback (3–6)
- Client-side frame selection (9 candidates → 6 by luminance), resize to
  1280 px, JPEG compression; no video is ever recorded or uploaded
- Server-side Claude vision analysis with structured outputs, Zod validation
  and one controlled repair pass
- Annotated result: ≤3 observations, ≤3 follow-up questions, frame browsing
- Privacy page, honest limitations, no database, no image storage
- Email+password gate (private preview) + fleet killswitch

## Numbers

- 6 frames × ~200 KB per analysis request; ≤3 questions per scan,
  ≤9 per browser session
- 43 unit tests; lint/typecheck/build green

## Known limitations

Blur is not detected in frame selection; markers are rough visual estimates;
no per-IP rate limiting (gate covers this while private). Full list in
README → Known limitations.
