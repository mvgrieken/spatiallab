# Release #003 — Does It Fit?

**Preview:** 2026-08-04 · **Status:** private preview achter login; AR Quick
Look wacht op fysieke iPhone-validatie (enige niet-simuleerbare stap)

## Het idee

> See it at real size. No app required.

Kies een meubel (kast, bureau, tafel, bank, koelkast), stel de echte maten in
centimeters in, en zet het object op ware grootte in je kamer via AR Quick
Look — rechtstreeks vanuit Safari. Op andere apparaten: een interactief
3D-voorbeeld plus het .usdz-bestand als download.

## Wat er is gebouwd

- Parametrische meubels uit pure cuboid-data (`lib/fit/objects.ts`,
  unit-getest op exacte maatvoering: bounding box == ingevoerde maten,
  op de vloer, gecentreerd)
- Client-side USDZ-export via three.js USDZExporter (spike-gevalideerd:
  stored zip, `model.usda` op offset 0, `metersPerUnit = 1`)
- Live 3D-voorbeeld (three.js, dynamic import — laadt pas op de
  experimentpagina), sleep-om-te-draaien, reduced-motion-vriendelijk
- **Geen AI, geen backend, geen upload**: alles blijft op het toestel
- Eerlijke maatgrenzen per objecttype; AR-detectie via `relList.supports("ar")`

## Publicatie-assets (concept)

- **Video-hook:** "Will that closet fit? See it at real size."
- **Eerste beeld (0–2 s):** vingers stellen 90 × 200 × 45 in.
- **Wow-moment:** seconde ~6 — het object staat levensgroot in de kamer.
- **Eerlijke beperking:** "It shows size, not looks — a simple stand-in,
  exactly as big as you typed."
- **Publieksvraag:** "Welk meubel had jij vooraf op ware grootte willen zien?"
- **Videoscript (≤30 s):** 0–2 s maten instellen · 2–4 s 3D-voorbeeld draait ·
  4–6 s tik "View at real size" · 6–18 s AR: object in de kamer, camera loopt
  eromheen, past-net-niet-moment tegen de muur · 18–24 s maat aanpassen en
  opnieuw plaatsen · 24–30 s tagline + "no app required".

## Bekende beperkingen

AR is Apple-only (Quick Look); vormen zijn bewust gestileerd; geen
productkoppeling; blob-URL → Quick Look is het enige onderdeel dat alleen op
een fysieke iPhone te verifiëren is (fallback: server-route, zie mini-brief).
